## 📌 Job Application Tracker 

### 🧩 Descripción del Proyecto  
Aplicación web para la gestión y organización de postulaciones laborales mediante un sistema visual tipo Kanban. Permite crear, editar y administrar candidaturas en distintas fases del proceso (Por aplicar, Aplicado, Entrevista, etc.), almacenando información detallada de cada oferta.

### 💻 Mi Rol en el Proyecto  
Me encargué principalmente del desarrollo **Frontend**, trabajando en:

- Desarrollo de la interfaz con React.js  
- Maquetación con HTML5 y CSS3  
- Lógica y dinamismo con JavaScript (ES6+)  
- Gestión de estado y renderizado dinámico de componentes  
- Implementación del sistema visual tipo Kanban  
- Consumo de API y conexión con backend  
- Autenticación de usuarios mediante JWT  
- Implementación de sistema CRUD completo desde el cliente  
- Diseño responsive y mejoras de UX/UI  
- Control de versiones con Git y GitHub  

### 🚀 Tecnologías Utilizadas  

- React.js  
- JavaScript (ES6+)  
- HTML5  
- CSS3  
- JWT (JSON Web Tokens)  
- Git  
- GitHub  

### 🎯 Objetivo del Proyecto  
Facilitar el seguimiento organizado de postulaciones laborales mediante una interfaz moderna, intuitiva y funcional que mejore la productividad del usuario.
